# GitHub Pages Source

This folder contains the GitHub Pages landing page for the poster QR code.

**Live URL**: https://mahdiAh1999.github.io/The-Fast-Track-To-Dose-Optimization/

To enable GitHub Pages:
1. Go to repository Settings → Pages
2. Set Source: Deploy from a branch
3. Branch: main, Folder: /docs
4. Click Save

The page will be live within a few minutes.
