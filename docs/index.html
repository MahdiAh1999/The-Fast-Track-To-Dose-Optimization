 Methodology

Our Solution — 4-Step Pipeline

An automated end-to-end pipeline that reads PACS dosimetric screenshots using OCR, computes DRLs, and validates results — with no PACS modification required.

①
EXTRACT

Python OCR (Tesseract + OpenCV) automatically reads PKA, Ka,r, and Fluoroscopy Time from PACS dosimetric screenshots — no PACS API required.

②
CALCULATE

Statistical analysis computes DRLs as the 3rd quartile (75th percentile) across n = 50 coronary angiography procedures, following ICRP/IAEA standards.

③
VALIDATE

99.43% accuracy (348/350 values correct) vs. manual extraction. Cross-validated on Siemens Artis Q and Philips Azurion systems.

④
IMPLEMENT

Seamless deployment — no PACS modification required. Adaptable to any PACS/IEC format. Open-source under MIT license.

 References

Key Literature

  • Tsuris & Dendalts (2023) — Cross-system validation reference for PACS dose extraction reproducibility on the Philips Azurion platform. Used as comparative benchmark for cross-system DRL generalizability.
  • ICRP Publication 135 — Diagnostic Reference Levels in Medical Imaging. International Commission on Radiological Protection. The foundational standard for DRL methodology and the 3rd-quartile Q3 approach applied in this study.
  • IAEA Human Health Series No. 19 — Establishing Guidance Levels in X-Ray Guided Medical Interventional Procedures. Provides the international framework for DRLs in interventional radiology.
  • IEC 60601-2-43:2022 — Medical electrical equipment — particular requirements for the basic safety and essential performance of X-ray equipment for interventional procedures. Referenced for dosimetric parameter standardization across PACS systems.
